# TCG Cargas — sitio web

Landing de TCG Cargas: conecta empresas que necesitan mover mercadería con camioneros verificados, en Argentina y Latinoamérica.

Es un sitio estático (HTML, CSS y JavaScript, sin compilar), así que se puede publicar tal cual en GitHub Pages, Vercel o Netlify.

## Archivos

- `index.html`: toda la página (estilos y animaciones incluidos).
- `assets/`: capturas de la app.
- `favicon.svg`: ícono de la pestaña.

## Pendientes antes de lanzar

- Poner los links reales de App Store y Google Play (hoy apuntan a `#descargar`).
- Reemplazar los corredores de la franja de rutas por corredores reales.
- Actualizar `APP_LOGIN_URL` en el script del final de `index.html` cuando la app tenga su dominio definitivo.
